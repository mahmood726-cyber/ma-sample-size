MASampleSize: A Browser-Based Prospective Meta-Analysis Sample Size Calculator

Protocol for a Single-File Interactive Tool for Required Information Size and Study Planning
Mahmood Alhusseini
Submitted: 2026-03-31  |  Registration: MSS-2026-001  |  License: MIT  |  Repository: github.com/mahmood726-cyber/ma-sample-size
Background. Prospective meta-analysis planning requires answering a question that existing tools do not address directly: how many studies—and how many patients—are needed before a pooled estimate can be considered conclusive? Trial Sequential Analysis (TSA) addresses the retrospective question (is existing evidence sufficient?), but no browser-based tool answers the prospective planning question for researchers designing cumulative synthesis strategies.

Objectives. To develop and validate a free, single-file, browser-native tool that calculates Required Information Size (RIS), estimates the number of studies needed to achieve target power, renders real-time power curves, and assesses adequacy of existing evidence against the RIS.

Methods. Single HTML file implementing binary and continuous sample-size formulae, D² heterogeneity adjustment, Abramowitz-Stegun normal quantile approximation, Canvas-based power curves, and localStorage state persistence.

Expected Outcomes. RIS, studies-needed estimate, four interactive power/MDE curves, and a traffic-light adequacy assessment against any pre-existing evidence base.

1. Background and Rationale

The cumulative evidence base in clinical medicine grows continuously. Systematic reviewers and prospective meta-analysis consortia must plan evidence synthesis prospectively: specifying effect size assumptions, heterogeneity expectations, and information requirements before data collection begins. Without such planning, meta-analyses risk underpowering (too few studies to detect a true effect) or are conducted sequentially without pre-specified stopping rules, inflating Type-I error.

The Required Information Size (RIS) concept—analogous to the sample size in an individual RCT but applied to pooled evidence—provides a principled framework. The TSA Pro tool (available at github.com/mahmood726-cyber/tsa-pro) addresses retrospective TSA with alpha-spending functions and futility boundaries. MASampleSize addresses the complementary prospective question, completing the planning-to-assessment lifecycle.

No existing freely available browser tool combines: (1) binary and continuous RIS calculation, (2) D² heterogeneity inflation, (3) studies-needed from average study size, (4) interactive power curves across k-studies and total N dimensions, and (5) existing-evidence adequacy assessment. This gap motivates the present tool.

2. Objectives

  1. Calculate the Required Information Size (RIS) for binary and continuous outcomes under user-specified design parameters.
  2. Estimate the number of studies needed to achieve RIS given an expected average study size.
  3. Render real-time interactive power curves across number of studies (k) and total sample size (N).
  4. Render minimum detectable effect (MDE) as a function of k and RIS sensitivity to I².
  5. Assess existing evidence (from an ongoing review) against the computed RIS and report a traffic-light adequacy rating.
  6. Export results as a JSON summary for audit trails.

3. Methods

3.1 Core Formulae

Binary outcome (two-arm, equal allocation). Per-arm sample size from two-proportion z-test:

n = (zα/2 + zβ)² × [p₀(1−p₀) + p₁(1−p₁)] / (p₀−p₁)²

Total N (both arms) = 2n. Relative Risk = p₁/p₀; Risk Difference = p₁−p₀.

Continuous outcome (two-arm, equal allocation). Two-sample t-test approximation:

n = 2(zα/2 + zβ)² × σ² / δ²

Cohen's d = δ/σ. Conventional thresholds: small=0.2, medium=0.5, large=0.8.

D² heterogeneity inflation. The diversity factor D² = I²/(1−I²) transforms the RIS:

RIS = N₀ × (1 + D²)   where D² = I²/(1−I²)

This formula follows Wetterslev et al. (2009) and is the same adjustment used in TSA software. At I²=0, RIS equals the unadjusted N; at I²=50%, RIS doubles; at I²=75%, RIS quadruples.

Studies needed. k = ceil(RIS / (2 × avgStudySize)), where avgStudySize is the expected per-arm size of contributing studies.

Power function. Given total accrued N and effect size δ (standardised):

Power = Φ(√(N/hetAdj) × δ/√2 − zα/2)

where hetAdj = 1 + D² and Φ is the standard normal CDF.

Minimum Detectable Effect. The MDE at a given N (80% power) is:

MDE = √(2(zα/2 + zβ)² / (N/hetAdj))

3.2 Normal Distribution Approximations

The standard normal CDF is approximated using the Abramowitz-Stegun error-function series (Handbook of Mathematical Functions, formula 7.1.26), which achieves maximum absolute error <1.5×10⁻⁷ across the entire real line. The inverse CDF (percent-point function) uses the rational approximation by Peter Acklam (2000), achieving maximum absolute error <3×10⁻⁹ in the central region.

3.3 Implementation Architecture

The tool is a single self-contained HTML file (1,825 lines, ~66 KB) requiring no server, no build step, and no external dependencies. Key design decisions:

  • Single file: embeds all CSS, JS, and markup inline for offline use and easy distribution.
  • Canvas charts: four power/MDE curves rendered natively via the HTML5 Canvas API with interactive slider controls and tooltip overlay.
  • localStorage persistence: state is saved to masscalc_v1_state on every input event and restored on page load.
  • Dark mode: CSS custom properties toggle between light and dark themes; preference saved to localStorage.
  • Four tabs: Study Parameters, Power Curves, Existing Evidence, Export.
  • Three example presets: statin mortality (green/adequate), novel anticoagulant bleeding (red/inadequate), exercise for depression (yellow/borderline).

3.4 Existing Evidence Assessment

The Existing Evidence tab accepts current pooled data from an ongoing review: number of studies (k), total N, pooled effect size, I², and 95% CI. The tool then computes:

  • Current power against the user-specified design effect.
  • Fraction of RIS accrued (N/RIS × 100%).
  • Qualitative traffic-light rating: Green (N ≥ RIS and CI excludes null), Yellow (N ≥ 75% RIS), Red (N < 75% RIS).
  • Accrual progress bar.
  • Remaining studies needed to reach RIS.

5. Validation Plan

Numerical outputs will be cross-validated against:

  • R pwr package (pwr.2p.test, pwr.t.test) for binary and continuous sample sizes.
  • Manual calculation with published TSA software reference values (Wetterslev et al. 2009, Thorlund et al. 2011).
  • Tolerance threshold: |relative error| < 0.1% for all reference values.

Safety checks will verify: div balance, script tag integrity, function name uniqueness, element ID uniqueness, and event listener cleanup (per html-apps.md rules).

6. Ethical Considerations

This tool processes no personal or clinical data. All computation is performed locally in the user's browser. No data is transmitted to any server. The tool is released under the MIT License to maximise open access.
